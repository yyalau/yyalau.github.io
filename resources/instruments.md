# Musical terms

| Term | Usage | Meaning |
|---|---|---|
| pizzicato (pizz.) | Strings | notes should be played by plucking the strings of a violin, viola, cello, etc., with the fingers instead of by using a bow |
| arco | Strings | a directive in music for string instruments to return to bowing after playing pizzicato |
| Sul ponticello | Strings | Play with the bow as close to the bridge as possible |
| up bow | Strings | The player draws the bow upward or to the left across the string instrument |
| down bow | Strings | The player performs the indicated note by drawing the bow downward or to the right across the string instrument |
| sul G | Strings | on the G string |
| (Italian) con sord./sordini<br>(French) avec sourdines | Strings, brass, piano | directs players to use a straight mute on string / brass / piano instruments |
| (Italian) Senza sord./ sordini<br>(French) sans sourdines | Strings, brass, piano | directs players to remove a mute on string / brass / piano instruments |
| una corda | Piano | with soft pedal pressed – used as a direction in piano music |
| tre corde | Piano | with soft pedal released – used as a direction in piano music at the close of a passage una corda. |
| con pedale | Piano | with sustain pedal pressed – used as a direction in piano music |
| Senza pedale | piano | with sustain pedal released – used as a direction in piano music at the close of a passage una corda. |
| Mano sinistra (m.s.) | Piano | a specific passage is to be played by the left hand |
| Mano destra (m.d.) | Piano | a specific passage is to be played by the right hand |
| arpeggiation | Any instrument | Spread out the notes of a chord, one after another 'in harp fashion' |
| Slur | Strings, woodwind, brass, piano, vocal | the notes it embraces are to be played without separation |
