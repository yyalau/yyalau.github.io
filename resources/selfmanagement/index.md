# iCanStudy Knowledge Base — Map of Content

A deduplicated, concept-oriented reference built from the entire iCanStudy course (17 modules + 34 Live Clinic sessions). Instead of re-watching scattered, overlapping videos, learn each concept **once** from its canonical topic note.

**New here?** Read the [README](README.md) for how this KB works, then follow the path below. Look up unfamiliar acronyms in the [Glossary](glossary.md). Trace any claim to its video in the [Source Map](source-map.md).

## Suggested learning path

The course is sequential by design — each technique builds on the previous one. A sensible order through the notes:

1. **Foundations** → [course-guide](topics/course-guide.md) (how to practice) + [learning-science](topics/learning-science.md) (why the methods work)
2. **The core system** → [bear-hunter-system](topics/bear-hunter-system.md) → [aiming](topics/aiming.md) → [note-taking](topics/note-taking.md) → [chunking-grinde](topics/chunking-grinde.md)
3. **Retain & revise** → [memorisation](topics/memorisation.md) → [revision](topics/revision.md)
4. **Manage yourself** → [time-management](topics/time-management.md), [habits-behaviour](topics/habits-behaviour.md), [mindset-emotion](topics/mindset-emotion.md), [focus-attention](topics/focus-attention.md), [sleep-rest](topics/sleep-rest.md)
5. **Apply** → [exam-technique](topics/exam-technique.md), [professional-learning](topics/professional-learning.md), [decision-making](topics/decision-making.md)
6. **Beyond** → [giving-back](topics/giving-back.md)

## All topics

### Foundations
- [**Course Guide & How to Practice**](topics/course-guide.md) — course structure, the COBES practice cycle, theory:practice ratio, checkpoints, the 30-day plan, goal setting.
- [**Learning Science & Theory**](topics/learning-science.md) — Cave Theory, memory & forgetting, spacing/interleaving/retrieval, desirable difficulty, marginal gains, layers of learning, order control.

### The core system (Bear Hunter System)
- [**The Bear Hunter System**](topics/bear-hunter-system.md) — Aim → Shoot → Skin overview, Hipshot variation, aim–shoot cycling, how the techniques integrate.
- [**Aiming & Question Quality**](topics/aiming.md) — generating curiosity, the two core questions, question quality, barriers, the traffic-light drill.
- [**Effective Note-Taking & Mind Maps**](topics/note-taking.md) — VPRefRE principles, visual/processed/relational/freehand/reflective notes, mind maps, app/device choices.
- [**Chunking, GRINDE Maps & Skin**](topics/chunking-grinde.md) — importance-based chunking, intuitive chunking, the GRINDE checklist, evaluating (Skin) your maps.

- [**Revision, Reconstruction, WPW & Multipass**](topics/revision.md) — revision strategy, reconstruction, Whole-Part-Whole, the multipass system, cramming.

### Manage yourself

- [**Habits, Procrastination & Behaviour Change**](topics/habits-behaviour.md) — the habit anatomy, PEER, BEDS-M, minimum viable goals, environment design.
