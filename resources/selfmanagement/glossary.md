# Glossary

Decoder for the acronyms, system names, and core terms used across the iCanStudy course. Many names appear in the transcripts as speech-to-text errors — the **Also heard as** column lists those mis-transcriptions so you can recognise them in the raw `resources/` files. Each entry links to the topic note that explains it in full.

## Acronyms & named systems

| Term | Expansion / meaning | Also heard as (ASR errors) | Note |
|---|---|---|---|
| **BHS** | **B**ear **H**unter **S**ystem — the integrated Aim → Shoot → Skin learning method | "boundary / Bayonetta / Beate system" | [bear-hunter-system](topics/bear-hunter-system.md) |
| **Aim / Shoot / Skin** | The three BHS phases: generate curiosity/questions → collect & organise information → evaluate & refine | "SKIM" = Skin | [aiming](topics/aiming.md) · [note-taking](topics/note-taking.md) · [chunking-grinde](topics/chunking-grinde.md) |
| **Hipshot** | First BHS variation: Aim + Shoot merged into one fast, mostly mental cycle (Hipshot → Skin) | "hip shot", "shooting from the hip" | [bear-hunter-system](topics/bear-hunter-system.md) |
| **Scan** | A shallow review pass used after Hipshot once Aim/Shoot are automatic | — | [bear-hunter-system](topics/bear-hunter-system.md) |

## Core concepts

| Term | Meaning | Note |
|---|---|---|
| **Cave Theory** | The brain evolved to solve survival problems (purposeful, clue-driven, pattern-finding), not to rote-study; effective learning works *with* this design | [learning-science](topics/learning-science.md) |
| **Desirable difficulty** | Effortful struggle is the signal that learning is happening; easy/comfortable study usually isn't learning | [learning-science](topics/learning-science.md) |
| **Marginal gains** | Small, compounding improvements (the "racing lap" / aggregation of marginal gains) | [learning-science](topics/learning-science.md) |
| **Illusion of fluency / competency** | Feeling like you know something ≠ being able to execute it; theory time must be paired with practice time | [learning-science](topics/learning-science.md) · [course-guide](topics/course-guide.md) |
| **Order control** | Deliberately choosing the sequence you learn in (backbone/logic first) rather than following the presented order | [learning-science](topics/learning-science.md) |
| **Layers of learning** | Backbone-first depth model ("onion of knowledge"); fundamental logic before details, aligned to Bloom's levels | [learning-science](topics/learning-science.md) |
| **Inquiry-based learning** | Question-driven priming that creates curiosity before collecting information | [aiming](topics/aiming.md) |
| **Traffic light** | Red–green inquiry drill used to prime and question-quality-check before studying | [aiming](topics/aiming.md) |
| **Chunking (importance-based)** | Grouping items that are important for the *same reason*; chunks are the unit of mind maps and WPW | [chunking-grinde](topics/chunking-grinde.md) |
| **Swiss-cheese model** | Knowledge has gaps ("holes"); revision passes are designed so holes don't line up | [revision](topics/revision.md) |
| **Reconstruction** | Rebuilding knowledge from memory (rather than re-reading); the difficulty is the signal it works | [revision](topics/revision.md) |
| **Cookie jar effect** | Engineer the environment (remove triggers) instead of resisting temptation with willpower | [habits-behaviour](topics/habits-behaviour.md) |
| **Deadly spiral** | Behaviours that remove the capacity to fix the root problem (e.g. rushing → no time to learn efficiency → more rushing) | [time-management](topics/time-management.md) |
| **Growth zone** | The stretch just beyond comfort where skill develops; entered via desirable difficulty | [mindset-emotion](topics/mindset-emotion.md) · [learning-science](topics/learning-science.md) |
| **Neuroticism** | A trait tendency toward negative emotion; managed via a prevention→planning→measurement→management→execution chain | [mindset-emotion](topics/mindset-emotion.md) |
| **Second-order observer** | Watching your own observing/thinking process — the meta-skill behind useful feedback | [giving-back](topics/giving-back.md) |
| **Kobe / COBE cycle** | See **COBES** above (same thing; transcript spelling varies) | [course-guide](topics/course-guide.md) |

> Tip: when a raw transcript spells a term oddly (e.g. "whole pothole"), match it against the **Also heard as** column rather than assuming it is a different concept.
